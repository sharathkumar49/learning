Part 1: Data Modeling & Schema Design  

# 1.1 Conceptual Modeling  
- Entity–Relationship (ER) Diagrams  
- Entities, attributes, relationships (1:1, 1:N, M:N)  
- Weak vs. strong entities, cardinality, participation constraints  

# 1.2 Logical Modeling  
- Translate ER to relational schema  
- Define tables, columns, data types  
- Identify primary keys (simple, composite)  
- Establish foreign keys and referential integrity  

# 1.3 Physical Modeling  
- Map logical schema to physical storage  
- Partitioning, clustering, file groups  
- Choose storage engines and file formats  
- Consider character sets, collations  

# 1.4 Normalization & Denormalization  
- First Normal Form (1NF)  
- Second Normal Form (2NF)  
- Third Normal Form (3NF) and Boyce–Codd NF  
- Higher NFs (4NF, 5NF) and when to denormalize  
- Pragmatic advice: “Don’t model the universe,” performance trade‐offs  

# 1.5 Modeling Patterns & Techniques  
- Lookup tables, link/junction tables for M:N  
- Inheritance (single table, class table, concrete table)  
- Recursive relationships (adjacency list vs. nested sets)  
- Temporal modeling (effective dates, bitemporal)  



Part 2: SQL & Implementation  

# 2.1 Data Definition Language (DDL)  
- 'CREATE' / 'ALTER' / 'DROP' databases, schemas, tables  
- Defining constraints: PRIMARY KEY, FOREIGN KEY, UNIQUE, CHECK  
- Managing indexes: B-tree, hash, composite, partial, covering  
- Views and materialized views  

# 2.2 Data Manipulation Language (DML)  
- 'SELECT': joins (inner, outer, cross), subqueries, CTEs  
- Window functions: ranking, moving aggregates, lag/lead  
- 'INSERT', 'UPDATE', 'DELETE' with performance considerations  
- Bulk operations, 'COPY' / 'LOAD DATA'  

# 2.3 Programmability  
- Stored procedures, functions, triggers  
- User‐defined types and domains  
- Transaction control: 'BEGIN' / 'COMMIT' / 'ROLLBACK'  



Part 3: Database Internals & Performance  

# 3.1 Storage Engines & File Structures  
- Page & block layout, extents  
- Buffer cache and I/O management  
- Compression techniques  

# 3.2 Indexing & Access Methods  
- B-tree, B+-tree, GiST, GIN, hash indexes  
- Index maintenance and fragmentation  
- Covering indexes and index-only scans  

# 3.3 Query Processing & Optimization  
- Parsing, rewriting, planning, execution phases  
- Cost‐based optimization, statistics  
- Explain plans, runtime metrics, profiling  

# 3.4 Partitioning & Sharding  
- Range, list, hash partitioning  
- Horizontal vs. vertical sharding  
- Geo‐partitioning and multi‐tenant schemas  



Part 4: Transactions, Concurrency & Recovery  

# 4.1 ACID Properties  
- Atomicity, Consistency, Isolation, Durability  
- Fail‐safe logging (WAL), checkpoints, recovery  

# 4.2 Isolation Levels & Phenomena  
- Read Uncommitted, Read Committed, Repeatable Read, Serializable  
- Dirty, non‐repeatable, phantom reads  

# 4.3 Concurrency Control  
- Locking protocols (row, page, table locks)  
- Deadlock detection & resolution  
- Multiversion Concurrency Control (MVCC)  

# 4.4 Distributed Transactions  
- Two‐phase commit (2PC), three‐phase commit (3PC)  
- XA transactions, saga pattern for long‐running processes  



Part 5: Data Warehousing & OLAP  

# 5.1 OLTP vs. OLAP Architectures  
- Characteristics & workload patterns  
- ETL vs. ELT pipelines  

# 5.2 Dimensional Modeling  
- Star schemas, snowflake schemas, galaxy/constellation schemas  
- Fact tables, dimension tables, slowly changing dimensions (SCD types 1–6)  

# 5.3 Columnar Storage & Massively Parallel Processing (MPP)  
- Columnar formats (Parquet, ORC)  
- Data warehouses: Redshift, Snowflake, BigQuery, Azure Synapse  

# 5.4 Analytical Operations  
- Roll‐up, drill‐down, slice & dice  
- In‐database aggregation, materialized aggregates  



Part 6: NoSQL & Polyglot Persistence

# 6.2 Document Stores

# 6.4 Graph Databases

# 6.5 Search & Analytics Engines

# 7.2 Replication Strategies

# 7.3 Consensus Algorithms

# 7.4 Distributed Query Processing
